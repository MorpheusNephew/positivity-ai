# Positivity AI collaboration guide

## Learning-first workflow

- This project is primarily for learning AI engineering by building it by hand.
- Explain concepts and meaningful tradeoffs before proposing an implementation.
- Do not edit files unless Jelani explicitly asks for an edit.
- Prefer small, incremental exercises that Jelani can implement independently.
- When reviewing code, explain why it works or does not work and point out relevant
  security, safety, testing, and maintainability considerations.
- Ask a short understanding-check question when it would help reinforce a concept.

## Project purpose

Build an application that uses AI to respond to prompts with positivity, encouragement,
and thoughtfulness. Do not present the product as therapy or crisis support.

## Documentation

- Keep the README focused on the product, setup, and current technical direction.
- Record actual lessons, questions, and decisions in `LEARNINGS.md` using dated entries.
